## 1. INICIO

O InurlBR Scanner Tool é uma interface gráfica (GUI) que auxilia na construcao de
comandos para o SCANNER-INURLBR (https://github.com/MrCl0wnLab/SCANNER-INURLBR).

Ao inves de digitar flags manualmente, voce seleciona opcoes na tela e
o comando e gerado automaticamente.

Exemplo de saida gerada:

    ./inurlbr --dork "site:alvo.com inurl:admin" -q 1,3,22,24 -s results.txt
